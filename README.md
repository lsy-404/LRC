# V宇宙词站

这是虚拟歌姬专辑的信息导航与歌词文件储存共享仓库。

## 下载方式

- **下载所有内容**：[点击这里](https://github.com/wuyilingwei/Medium5-LRC/archive/refs/heads/main.zip) 下载完整仓库
- **下载单个专辑**：在下方目录中找到对应专辑，点击 📦 下载专辑歌词包
- **下载单首歌曲**：展开专辑详细曲目，点击歌曲旁的 📥 下载按钮
