# meta.toml 规范

每个专辑文件夹（`res/[专辑名]/`）中应包含一个 `meta.toml` 文件，用于存储专辑元数据信息。

## 文件格式

`meta.toml` 使用 TOML 格式，支持以下字段：

```toml
年份 = "2025-08-12"
出品 = "五维介质Official"
发布 = "https://www.bilibili.com/video/BV1uKtSz6EgF/"
购买 = "![淘宝](https://item.taobao.com/item.htm?id=991410246698)"
歌词制作 = "某某"
演唱 = ["苍穹", "Melo"]
作词 = ["苍穹"]
作曲 = ["Melo"]
调校 = []
```

## 字段说明

| 字段 | 类型 | 是否必需 | 说明 |
| ---- | ---- | -------- | ---- |
| 年份 | 字符串 | 否 | 支持 `YYYY` / `YYYY-MM` / `YYYY-MM-DD`，用于首页排序（缺失月/日按 1 处理） |
| 出品 | 字符串 | 否 | 专辑出品方 |
| 发布 | 字符串 | 否 | 发布链接，支持纯 URL 或 Markdown 字符串 |
| 购买 | 字符串 | 否 | 购买链接，支持纯 URL 或 Markdown 字符串（如 `![淘宝](...)`） |
| 歌词制作 | 字符串 | 否 | 歌词制作人员 |
| 演唱 | 字符串数组 | 否 | 演唱者列表 |
| 作词 | 字符串数组 | 否 | 作词者列表 |
| 作曲 | 字符串数组 | 否 | 作曲者列表 |
| 调校 | 字符串数组 | 否 | 调校者列表 |

## 注意事项

1. 所有字段都可省略，空字段会在页面中自动忽略。
2. `发布`、`购买` 字段若填写纯 URL，会自动渲染为可点击链接。
3. `购买` 字段支持直接写 Markdown 文本，例如：

```toml
购买 = "![淘宝](https://item.taobao.com/item.htm?id=991410246698)"
```

4. 如果需要明确无信息，建议使用空字符串 `""` 或空数组 `[]`。

## 集成方式

1. 在 `res/[专辑名]/` 下维护 `meta.toml`
2. 运行 `npm run generate-md` 生成文档
3. 脚本会自动读取 `meta.toml` 并生成专辑页与首页

## 自动生成脚本

脚本位置：`.github/scripts/generate_md.py`
