# 调研记录

- [上传 LRC 被忽略] -> `pipeline.classify()` 仅将 `.txt` 归入文本，`.lrc` 会进入 `other` -> 需要显式分类并构建权威轨道。
- [自动处理会改写 LRC] -> 普通 `build_track_lrc()` 会重排时间、做简繁转换并重新输出 -> 权威轨道必须绕开该路径。
- [元数据保存可能重序列化歌词] -> 工作台 `toDraft()` 会由编辑器行重新生成 LRC -> 权威轨道保存时需原样透传。
- [逐字对齐必须不反写] -> 使用原 LRC 的行边界筛选 STT 字时间，只输出独立 `.klrc` -> 标准 `.lrc` 在草稿和 finalize 中始终复用 source 文本。
