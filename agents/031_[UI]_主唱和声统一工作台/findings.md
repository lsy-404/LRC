# 调研记录

- [现有呈现] -> `EditBox.vue` 通过下拉框切换当前声部，未选声部在工作区下方以 `eb-vocal-overlap` 只读显示 -> 主唱和声并非同一编辑时间轴，需改为同一行流。
- [术语] -> 旧实现含“合音”“声部”“添加声部” -> 用户可见文字需改为“和声”。
- [实现] -> 所有歌词流改为同一 `.eb-workbench > .eb-editor-panel` 内连续纵向渲染，主唱和声各用带文字的颜色条标识 -> 不再切换下拉或显示只读重叠区。
- [历史与保存] -> 编辑动作以轨道根对象记录历史，和声的行/逐字对象沿原有序列化路径保存 -> 迁移来回、时间偏移和撤回恢复不丢失数据。
- [多重唱] -> 不能把所有附加歌词流收敛为同一个 `harmony` id，否则会产生重复渲染 key -> 保留每条和声的唯一稳定 id，显示和保存名称统一为“和声”。
