# 关于本站

## 资源来源

本站主要收集网上公开的虚拟歌姬团体官方及第三方专辑的 LRC 歌词文件。

所有歌词内容均来自于：
- 公开发布的歌词资源
- 社区贡献的歌词内容
- 少量对于缺失资源的补充和修正
