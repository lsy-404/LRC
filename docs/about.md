# 关于本站

V宇宙词站是一个由社区驱动维护的类 wiki 项目，旨在为虚拟歌姬专辑提供信息导航和歌词共享资源库，和任何官方无关。

可以是中v也能是日v还能是五V —— 星菌

欢迎通过 GitHub 贡献任何有虚拟歌姬专辑相关的资源，无论是专辑信息、歌词文件还是修正错误，详情请参阅 [贡献指南](./CONTRIBUTING.md)。

## 资源来源

所有歌词内容均来自于：
- 公开发布的歌词资源
- 社区贡献的歌词内容
- 少量对于缺失资源的补充和修正

## 关于 CC BY-NC-SA 4.0 中“非商业性使用”的本站定义

鉴于知识共享（Creative Commons）组织建议权利人对“非商业性”的具体意图进行澄清，本站特此对本项目所涉及歌词资源的非商业性使用（Non-Commercial）界限作出如下说明：

### 商业行为的具体认定

根据本站意图，以下行为将被视为违反“非商业性使用”条款，除非另行获得书面许可：

**直接营利** - 包含但不限于单独或打包售卖歌词文件（如 LRC、TXT 格式）、销售歌词数据库。

**变相收费** - 以歌词作为核心内容进行收费订阅，或为歌词下载/访问设置付费墙。

**间接收益** - 主要目的旨在通过分发、转授权本站歌词资源来获取直接或间接利益。

### 商业性豁免

本站鼓励 LRC 歌词在音乐传播中的合理应用。即便使用者为营利性实体（如商业音乐平台、播放器软件），只要同时满足以下条件，其使用行为将被视为本站认可的“非商业性”兼容场景或自动获得豁免授权：

**场景限定** - 仅限于音乐播放过程中或合理的展示页面中作为辅助信息的同步展示。

**非核心定价** - 不得将歌词作为独立商品或增值服务的核心卖点进行单独收费。

**禁止再分发** - 不得对本站歌词资源进行二次销售、独立授权或大规模 API 转发。

### 关于分发方式的特别限制

为确保本站歌词资源的公益性与易得性，任何对本站资源的二次分发（Redistribution）必须满足以下**“无门槛”**要求，否则将被视为以“获取间接商业利益”为目的未经授权的侵权行为：

**无门槛** - 资源分发页面及过程中不得强制要求访客登录、注册、关注账号或下载特定的客户端软件后方可下载。

**访问带宽** - 分发节点必须为访客提供合理的下载速度（原则上不低于 1 Mbps），不得通过物理限速手段诱导用户购买加速包或会员。

**禁止引流** - 不得利用本站资源作为诱饵，强制用户完成特定商业任务（如观看强制性广告、点击推广链接）以换取下载权限。
