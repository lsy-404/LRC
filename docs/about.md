# 关于本站

V宇宙词站是一个由社区驱动维护的类 wiki 项目，旨在为虚拟歌姬专辑提供信息导航和歌词共享资源库，和任何官方无关。

可以是中v也能是日v还能是五V —— 星菌

欢迎通过 GitHub 贡献任何有虚拟歌姬专辑相关的资源，无论是专辑信息、歌词文件还是修正错误，详情请参阅 [贡献指南](./CONTRIBUTING.md)。

## 资源来源

所有歌词内容均来自于：
- 公开发布的歌词资源
- 社区贡献的歌词内容
- 少量对于缺失资源的补充和修正
